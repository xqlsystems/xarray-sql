1A Dataset is a table

Registering a Dataset gives SQL a table with one row per grid cell: a column for each dimension and one for each data variable. Nothing is copied. Each chunk becomes a partition of the table, read only when a query needs it. Hover over the grid or the table to match cells to rows. 

import duckdb, xarray as xr, xarray_sql as xql

ds = xr.open_zarr("air.zarr")  # air(time: 8, lat: 6, lon: 8)
con = duckdb.connect()
xql.register(con, "air", ds, chunks={"time": 4, "lat": 3, "lon": 4})
